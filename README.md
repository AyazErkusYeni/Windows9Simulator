### Windows 9 Simülatörü
Bu proje, asla çıkmamış olan efsanevi Windows 9 işletim sistemi için hazırlanmış retro tarzda bir masaüstü simülatörüdür. Python ve `tkinter` kütüphanesi kullanılarak geliştirilmiştir. GitHub üzerinde sergilemek ve nostaljik bir hava yakalamak için tasarlanmıştır.
Özellikler
Klasik Retro Masaüstü: Nostaljik camgöbeği (Teal) arka plan ve ikon düzeni.
Gelişmiş Başlat Menüsü: Programlara hızlı erişim ve sistemi kapatma seçeneği.
Sürükle-Bırak Pencere Sistemi: Başlık çubuğundan tutularak masaüstünde hareket ettirilebilen dinamik pencereler.
Yerleşik Uygulamalar:
Not Defteri (Notepad): Metin yazıp düzenleyebileceğiniz alan.
Hesap Makinesi: Temel matematiksel işlemleri yapabilen çalışan bir araç.
Komut İstemi (CMD): Özel komutları (örn. `help`, `version`, `clear`, `date`) çalıştıran terminal simülasyonu.
Canlı Görev Çubuğu ve Saat: Sağ alt köşede anlık güncellenen sistem saati.
Kurulum ve Çalıştırma
Projeyi çalıştırmak için bilgisayarınızda Python'ın kurulu olması yeterlidir. Herhangi bir harici kütüphane yüklemenize gerek yoktu.
```bash
# Depoyu klonlayın
git clone https://github.com/AyazErkusYeni/windows9-simulator.git

# Proje dizinine girin
cd windows9-simulator

# Simülatörü çalıştırın
python windows9_sim.py
```
